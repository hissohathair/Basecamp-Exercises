Q1Describe your platform's approach to real-time threat detection. What data sources are ingested, and what is the average detection-to-alert latency?

Helios Sentinel employs a multi-layered, real-time threat detection engine that combines three complementary methodologies: signature-based matching for known threat patterns, behavioral analysis for anomalous activity, and ML-driven anomaly detection for novel or zero-day threats. Together, these layers provide broad coverage across the MITRE ATT&CK framework, with detection rules validated quarterly.

Data Sources Ingested:
The platform ingests a wide range of telemetry across the enterprise attack surface, including:
- Endpoint telemetry: Process events, file system changes, and network connections
- Cloud workload logs: AWS CloudTrail, Azure Activity Log, and GCP Audit Log
- Network flow data: NetFlow v9 and IPFIX
- Email gateway events

The underlying SIEM correlation engine is capable of processing up to 50,000 events per second (EPS) per tenant, ensuring performance at enterprise scale without loss of fidelity.

Detection-to-Alert Latency:
Helios Sentinel delivers industry-leading detection speed across both detection modalities:
- Signature-based (known threats): Average latency of 2.3 seconds
- Behavioral/ML-based (anomalies): Average latency of 18 seconds

This translates to a practical guarantee of sub-3-second detection for known threat patterns and under 20 seconds for behavioral anomalies. Detection quality is maintained at a 99.7% true positive rate across our top 100 detection rules, minimizing alert fatigue for security operations teams.

Q5How does your platform handle data residency requirements for customers operating in the EU? Describe encryption at rest and in transit.

Helios Security fully supports EU data residency requirements through the following measures:

Data Residency & Sovereignty
Helios operates dedicated infrastructure within the European Union across two AWS regions: Frankfurt (eu-central-1) and Dublin (eu-west-1). Customers selecting an EU residency configuration are guaranteed that their data never leaves the designated region — there is no cross-region replication to non-EU infrastructure. Customers may select their preferred EU region at tenant provisioning.

Encryption at Rest
All customer data stored on the Helios platform is encrypted using AES-256-GCM, a high-strength authenticated encryption standard. Helios supports customer-managed encryption keys via AWS Key Management Service (KMS) or a Bring Your Own Key (BYOK) model, giving EU customers full control over key lifecycle management and the ability to revoke access at any time.

Encryption in Transit
All data in transit — including API communications and endpoint agent telemetry — is protected using TLS 1.3, the current industry-best transport security standard. Endpoint agents additionally employ certificate pinning to prevent man-in-the-middle attacks and ensure agent-to-platform communications are authenticated against a known certificate chain.

GDPR & Contractual Compliance
A GDPR-compliant Data Processing Agreement (DPA) is included as standard in all EU customer contracts, addressing lawful basis for processing, data subject rights, and sub-processor obligations. The platform supports configurable per-tenant data retention policies; defaults are 90 days for raw telemetry and 13 months for aggregated alerts.

Security Assurance
Helios undergoes annual third-party penetration testing conducted by NCC Group, and holds active ISO 27001:2022 and SOC 2 Type II certifications, both independently audited in 2024.
